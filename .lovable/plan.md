# Инструкция для психологов: как попасть в кабинет специалиста

## Задача

Подготовить короткую пошаговую инструкцию для специалистов (PDF-подобный документ для скачивания и текст для отправки в мессенджере), чтобы не объяснять вход в кабинет каждой психологу лично.

## Ответы на вопросы (основа инструкции)

- Отдельной регистрации для специалистов нет — регистрируются как обычный пользователь (email + пароль), вход сразу.
- Отдельного входа и отдельной кнопки на главном экране нет — одно приложение, один адрес.
- Пункт «Кабинет специалиста» появляется в меню только после того, как администратор привяжет аккаунт специалиста к его карточке в каталоге (Модерация → Психологи → «Привязать вход» → email специалиста).
- Ссылка на кабинет: пункт «Кабинет специалиста» в меню («Служебное»): телефон — кнопка «Меню» внизу экрана, компьютер — левое меню. В кабинете: заявки, подтверждение времени, чат с клиентом.

## Что будет сделано

1. Создать документ `/mnt/documents/Nur_Balance_Инструкция_для_психологов.md` с готовым текстом инструкции (шаги ниже), в фирменном тоне приложения, на русском языке.
2. Дать тот же текст короткой версией прямо в чат — можно сразу переслать психологу.

## Текст инструкции (содержание документа)

**Как открыть кабинет специалиста в Nur Balance — 4 шага**

1. **Зарегистрируйтесь как обычный пользователь.** Откройте приложение (адрес пришлёт администратор), нажмите «Зарегистрироваться», укажите имя, email и пароль. Подтверждение по почте не нужно — вход сразу.
2. **Сообщите свой email администратору.** Напишите тот же email, с которым зарегистрировались, — администратор привяжет ваш аккаунт к вашей карточке в каталоге специалистов.
3. **Дождитесь появления пункта «Кабинет специалиста».** Откройте меню: на телефоне — кнопка «Меню» внизу экрана, вверху будет блок «Служебное»; на компьютере — левое меню, раздел «Служебное» внизу. Там появится «Кабинет специалиста».
4. **Работайте в кабинете.** Видите заявки клиентов: «Подтвердить время» — фиксирует дату и длительность, «Отклонить»/«Отменить», «Консультация состоялась». После подтверждения открывается личный чат с клиентом («Открыть чат») — переписка, голосовые и вложения.

Примечания: отдельной регистрации для специалистов нет; если пункта «Кабинет специалиста» нет — аккаунт ещё не привязан, напишите администратору. Пароль можно восстановить кнопкой «Забыли пароль?» на экране входа.

## Технические детали

- Источник истины — код: `AppShell.tsx` показывает пункт «Кабинет специалиста» только при наличии карточки `therapists` с `user_id` = аккаунт; привязку делает `linkTherapistAccount` (админ) из `TherapistsAdminPanel.tsx` («Привязать вход»).
- Регистрация: `/auth`, email+пароль, без подтверждения письма; восстановление пароля — «Забыли пароль?».
- Кабинет: `/therapist-desk`, чат — `/therapy-chat` (создаётся автоматически при подтверждении заявки).
- Изменений в коде приложения не требуется.
