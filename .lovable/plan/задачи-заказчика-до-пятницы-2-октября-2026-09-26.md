# Задачи заказчика до пятницы (2 октября)

Проверил документ и текущее состояние приложения. Три задачи, по одной на каждый пункт письма.

## 1. Учёт консультаций для расчёта комиссии

Данные уже есть: каждая заявка хранит психолога, клиента, дату и время приёма, длительность и статус («подтверждена» / «завершена»). Не хватает только удобного списка для подсчёта.

Делаем:
- Новый экран «Учёт консультаций» в разделе модерации (видит только администратор).
- Список подтверждённых и проведённых консультаций: психолог, клиент, дата и время, длительность, статус.
- Фильтр по месяцу и по психологу, итог за период: количество консультаций и суммарные часы.
- Этого хватит, чтобы в конце месяца посчитать первую комиссию вручную. Автоматический расчёт комиссии в процентах — отдельная задача позже, когда будут согласованы ставки.

## 2. Личный чат клиент–психолог внутри приложения

Переиспользуем готовую механику чата поддержки (живые сообщения, запись голоса, загрузка файлов), но как отдельный канал, привязанный к заявке.

Делаем:
- Чат открывается автоматически, когда заявка подтверждена (статус «назначена»): у клиента — кнопка «Написать специалисту» в его заявке, у психолога — в кабинете специалиста.
- Текстовые сообщения в реальном времени, уведомления о новых сообщениях (как в чате поддержки — колокольчик и бейдж).
- Голосовые сообщения — переиспользуем запись аудио из дневника.
- Фото и файлы из галереи через кнопку-«скрепку» — переиспользуем загрузку из дневника, приватное хранилище, файлы видят только участники чата.
- Доступ: чат читают только клиент и его психолог (и администратор для модерации). Правила доступа — на уровне базы.
- Видеозвонок не делаем — отдельная задача на будущее, как и просит заказчик.

## 3. Убрать контакты психолога из публичной карточки

Сейчас в карточке специалиста показываются телефон, email и Instagram (кнопки «позвонить», «написать», «@instagram»).

Делаем после того, как чат готов:
- Убираем блок контактов из каталога и из формы записи.
- Вместо них — подсказка: «Общение со специалистом — в чате приложения после подтверждения записи».
- Контакты остаются в базе и видны администратору в модерации (для служебной связи), но не показываются пользователям.

## Порядок работ

1. Учёт консультаций (быстро, данные уже есть) — нужен к концу месяца для комиссии.
2. Чат клиент–психолог (основная работа недели).
3. Скрытие контактов — сразу после чата, одним шагом.

## Технические детали

- Новые таблицы `therapist_chats` и `therapist_messages` (текст / голос / файл, привязка к заявке), гранты и RLS: участники чата + администратор; realtime-подписка как в `buddy_messages`.
- Приватный бакет для вложений чата (как `buddy-media`), доступ по временным ссылкам.
- Переиспользуем `MediaMessageRecorder` (голос) и механизм загрузки из `src/lib/upload.ts`.
- Экран учёта — чтение `therapist_requests` со статусами `scheduled`/`done`, группировка по месяцам, итоги.
- Скрытие контактов — удаление блока `TherapistContacts` из `src/routes/_authenticated/therapists.tsx`; поля в базе и админке сохраняются.
